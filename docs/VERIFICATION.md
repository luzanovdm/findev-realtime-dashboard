# Local Verification

This record distinguishes compiled-module, worker, browser, and hosting evidence. The runtime
observations below used commit `e474e6b91dcb5903033ad4327d40ae44a1958573` on October 21, 2026.
The deployment preparation that follows that commit is checked separately before publication.

| Layer                      | Environment and input                                                                       | Result                                                                                                                                                                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Clean install              | Node 24.21.0, npm 11.19.0, `npm ci`                                                         | Completed; npm reported zero vulnerabilities.                                                                                                                                                                                                                                   |
| Locked quality command     | `npm run check`                                                                             | 130 Angular/Vitest tests, 8 compiled-Wasm and production-worker tests, formatting, and production build passed. No TODO tests remain.                                                                                                                                           |
| Worker/Wasm integration    | Built worker and Wasm over loopback HTTP                                                    | Start, batch, Pause/Resume, Apply/reset, Wasm 404, invalid Wasm, and HTML SPA fallback covered. The Wasm response uses `application/wasm`.                                                                                                                                      |

The soak validates accounting for the number of batches actually generated. The requested 50 ms
interval is pacing between completed batches, so throughput may be below the nominal 20,000 updates
per second under host scheduling or worker processing load.

Remote Cloudflare Pages behavior, direct-route refreshes on the live host, Wasm response headers on
the live host, and automatic push-to-live deployment remain unverified until the repository is
published and connected. The local emulator is evidence for the packaged assets and Pages routing
rules, not a successful remote deployment.
